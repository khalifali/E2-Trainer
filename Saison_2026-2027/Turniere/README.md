# Turniere

Hier werden bestätigte Turniere mit Datum, Spielplan, Kaderorganisation, Treffpunkt, Material und Rückblick abgelegt. Noch keine Turniere eingetragen.

Benennung: `JJJJ-MM-TT_Turniername`. Startpunkt: [Aktivitätsvorlage](../../Vorlagen/Aktivitaet.md), bei Bedarf ergänzt um die [Spieltag-Vorlage](../../Vorlagen/Spieltag.md).
